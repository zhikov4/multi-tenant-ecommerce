# Multi-Tenant eCommerce Platform

Laravel 12 + Vue 3 + Inertia.js + Stancl Tenancy

**Repository:** https://github.com/zhikov4/multi-tenant-ecommerce  
**Task by:** Eng Mohab Mamdouh  
**Last updated:** March 14, 2026

---

## Tech Stack

| Layer | Technology |
|---|---|
| Backend | Laravel 12.x |
| Frontend | Vue 3 + Inertia.js |
| Multi-Tenancy | Stancl Tenancy v3.9 |
| Database | MySQL 8.x |
| CSS | Tailwind CSS 3.x |
| Build Tool | Vite 7.x |
| Routing (JS) | Ziggy |

---

## Architecture

This platform uses **multi-database tenancy** — each store (tenant) gets its own isolated MySQL database.
